## 中文

- 应用始终使用项目目录内的官方 NuGet Python 3.12.10 x64，包含 venv/pip；不扫描或复用系统 Python，不运行 Python EXE/MSI，不更改注册或 PATH。未知/修改过的运行时及外部 Python 建立的旧环境保持原样。
- Python 下载纳入镜像开关：已核实的华为云 NuGet 镜像失败后回退官方源，两者校验同一固定官方 SHA256。持续有数据不再受 180 秒总时限影响；保留连接/无数据读取超时、有界重试、取消、体积和解压路径限制及原子发布。
- 清华 TUNA PyPI 首次默认启用，已有审查记录和明确选择优先。可切换官方源；只影响项目命令，不修改全局 pip 配置。
- Windows 桌面使用兼容 DirectML 的 Python3.12 x64、torch-directml0.2.5.dev240914 / torch2.4.1；CUDA12/13 依据硬件、驱动和 wheel 选择，CPU 保留。
- 原生独立目录已完成镜像部署、私有 venv、TUNA 完整解析/安装、DirectML 与 NumPy 数值交换，以及由生成脚本打开真实可见桌面窗口。冻结 EXE 的自检、GUI、私有部署及建 venv 均通过。完整安装器回归：474 passed、2 Windows 平台跳过、69 subtests。

已知限制：仅 Windows x64 私有运行时；固定 Python3.12.10 并非最新3.12安全补丁。官方 NuGet 不含 Tcl/Tk，安装器 EXE 自带 GUI 运行时，项目使用 Qt。最小 DirectML 检查不是完整仿真、精度或性能保证，未覆盖所有 GPU 品牌/驱动。alpha.1 资产保留。
