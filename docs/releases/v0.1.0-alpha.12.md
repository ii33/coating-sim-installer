# v0.1.0-alpha.12：可选源码 CLI 分环境运行时

本次为 Windows x64 安装器预发布版。EXE 自带安装界面所需的运行时，启动安装器无需预装 Python；这不等于已完成应用全运行时安装验收。

- 新增源码 CLI 命令 `runtime-roles-plan` / `runtime-roles-install`，将应用/CPU、DirectML、适配硬件的 CUDA 和外观渲染依赖分别管理。选择 CUDA 不会排除独立 DirectML 环境；CPU 沉积角色复用应用环境。
- 创建或修复只使用已验证的项目私有 Python。执行前复核固定目录、解释器来源和已审查依赖范围；失败、取消或并发修改时保留现场及无关内容。
- 运行时绑定采用完整私有基础 Python 清单及解释器、配置、包元数据校验；旧绑定不能把部分修复误报为完成。中断锁和冲突副本保留，并给出可恢复诊断。
- 文本测试显式使用 UTF-8，并在中文及空格路径下验证配置与生产者/消费者契约。

## 使用范围与已知限制

新能力目前仅为**可选源码 CLI**：从安装器源码目录运行 `python -m tools.dependency_manager runtime-roles-plan ...`，审查计划后执行对应 `runtime-roles-install`。当前 EXE 入口及默认 GUI 安装流程未接入这些分环境命令；请勿把本版理解为默认一键安装已完成分环境改造。源码 CLI 前端仍需要可用的 Python 来启动，应用环境仅使用项目私有 Python。

本版不新增膜系 GPU 前向计算。包安装及绑定一致性不是 GPU 就绪证据，也不代表完整原生依赖闭包、CUDA/DirectML 数值或性能合格。尚未完成干净 Windows、无外部 Python 条件下的应用全流程安装、取消和恢复验收。固定私有 Python 3.12.10 并非最新安全补丁。

发布工作流须先通过完整离线测试、PE 版本/GUI 子系统检查、冻结自检、中文空格路径下的可见 GUI 冒烟，以及借用显式构建 Python 创建临时 no-pip venv 的离线子进程诊断。最后一项不是“无外部 Python”验收。跨仓库契约测试已在助手主机上另行执行；普通 Windows CI 未提供主程序 checkout 时会明确跳过这两项。

EXE **未签名**。请同时下载本页 EXE 和 `SHA256SUMS.txt`，核对 SHA-256 后使用。历史标签、Release 和文件保留。
